# FB-Signup-Clone

A simple Facebook signup page clone built with HTML and CSS.

## Overview

This project recreates the Facebook account creation form layout using static web files. It includes form fields for name, date of birth, gender selection, email, and password input.

## Files

- `index.html` — main page structure and form markup
- `style.css` — styling for the layout, form, and responsive appearance

## Usage

1. Open `index.html` in a web browser.
2. Review the layout and styling.
3. Customize the form or design as needed.

## Notes

- This is a front-end clone only; it does not include any backend or form submission handling.
- The project is intended for learning and UI practice.
